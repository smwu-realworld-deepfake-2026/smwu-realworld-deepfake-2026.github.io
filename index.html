연구 배경

SNS를 거친 영상에서는 탐지기가 제 성능을 내지 못합니다

딥페이크 탐지 모델은 보통 압축이 약한 고화질 데이터로 학습합니다. 하지만 실제로 퍼지는 영상은 SNS와 메신저를 거치며 손실 압축을 반복해서 겪고, 그 과정에서 모델이 의존하던 공간 픽셀 정보가 크게 오염됩니다.

기준 모델인 MoE-FFD는 ViT-B/16에 LoRA-MoE와 Adapter-MoE를 결합한 모델입니다. 전문가 선택(라우팅)을 공간 토큰에만 의존하기 때문에, 압축이 강해지면 라우팅 자체가 흔들립니다.

제안 방법

특징과 데이터, 두 수준에서 압축에 대비합니다

압축에도 비교적 보존되는 FFT 위상(phase) 정보로 전문가 선택을 보정하고, 학습 단계에서 재압축 열화를 미리 겪게 합니다.

Phase Module과 Phase-Guided MoE Routing

입력 이미지를 2D FFT로 변환한 뒤 진폭은 버리고 위상만으로 이미지를 복원합니다. 경량 CNN이 여기서 128차원 특징을 뽑고, 선형 투영으로 ViT와 같은 768차원에 맞춥니다.

x_global 768+z_freq 768=게이트 입력 1536
  • 공간 특징이 압축으로 오염돼도 위상 특징이 올바른 전문가 선택을 안내합니다.
  • 추가 학습 파라미터는 약 14만 개로 전체의 1% 미만입니다.

JPEG 압축 증강

학습할 때 50% 확률로 품질 30~70 사이의 JPEG 압축을 무작위로 적용합니다. 배포 환경에서 일어나는 재압축 열화를 학습 단계에서 미리 경험하게 해 내성을 키웁니다.

  • 학습에만 적용하고 평가 데이터는 그대로 둡니다.
  • Phase Module과 함께 쓸 때 강한 압축에서 효과가 가장 큽니다.

실험 결과

압축이 강해질수록 차이가 벌어집니다

FF++ c23으로 학습한 세 모델을 압축 강도를 높여가며 평가했습니다. 약한 압축에서는 세 모델이 비슷하지만, 압축이 강해질수록 제안 모델(Phase + JPEG Aug)의 성능이 가장 덜 떨어집니다.

MoE-FFD (baseline) + JPEG Aug + Phase + JPEG Aug (제안)

JPEG 품질 100, 80, 60은 FF++ c23 검증셋을 해당 품질로 재압축해 평가했고, c40은 FF++ 고압축 테스트셋입니다. 지표는 프레임 단위(frame-level) AUC(%)입니다.

데모 시스템

사진 한 장으로 네 모델을 비교해볼 수 있습니다

학습한 모델 네 개를 AWS 서버리스로 배포했습니다. 브라우저에서 얼굴 사진을 올리고 모델을 고르면 판정, Fake 확률, Grad-CAM 히트맵을 확인할 수 있습니다.

  1. 업로드 주소 발급: API Gateway와 Lambda가 5분짜리 S3 서명 URL을 발급합니다.
  2. S3 직접 업로드: 브라우저가 서버를 거치지 않고 사진을 S3에 올립니다.
  3. 추론: SageMaker 서버리스 엔드포인트가 학습 때와 같은 방식으로 얼굴을 자르고 판정합니다.
  4. 결과 기록: Grad-CAM은 S3에, 판정 이력은 DynamoDB에 저장됩니다.
